Code signing policy

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

What is signed

Only the Windows builds of souldew are signed through SignPath: the installer (souldew-<version>-win-x64-setup.exe) and the programs inside it. They are built by GitHub Actions from the public repository github.com/souldewapp/souldew – nothing is built or signed on a private computer. The macOS and Linux builds are not signed through SignPath.

Team roles

  • Committers and reviewers: souldew maintainers
  • Approvers: souldew owner

Every signing request is approved by hand before a release is signed.
