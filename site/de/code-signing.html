Code signing policy

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Kostenlose Code-Signierung durch SignPath.io, Zertifikat von der SignPath Foundation.

Was signiert wird

Über SignPath signiert werden nur die Windows-Versionen von souldew: das Installationsprogramm (souldew-<version>-win-x64-setup.exe) und die Programme darin. Sie werden von GitHub Actions aus dem öffentlichen Repository github.com/souldewapp/souldew gebaut – nichts wird auf einem privaten Computer gebaut oder signiert. Die Versionen für macOS und Linux werden nicht über SignPath signiert.

Rollen im Team

  • Committers and reviewers: souldew maintainers
  • Approvers: souldew owner

Jede Signierung wird von Hand freigegeben, bevor eine Version signiert wird.
