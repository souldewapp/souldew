4. Abfrage der aktuellen Version

Damit die Download-Knöpfe direkt auf die neueste Version zeigen, fragt dein Browser beim Laden der Seite die öffentliche Schnittstelle von GitHub (api.github.com) nach dem neuesten Release. Dabei wird deine IP-Adresse an GitHub übermittelt (siehe Abschnitt 2). Rechtsgrundlage ist Art. 6 Abs. 1 lit. f DSGVO; unser berechtigtes Interesse ist ein funktionierender Download. Die Antwort (Versionsnummer, Dateinamen, Größen) wird höchstens 30 Minuten im Sitzungsspeicher deines Browsers (sessionStorage) zwischengespeichert, damit beim Wechsel zwischen den Sprachversionen nicht erneut gefragt wird; sie verlässt deinen Browser nicht und wird beim Schließen des Tabs gelöscht. Ohne JavaScript führen die Knöpfe zur Release-Seite auf GitHub.

Welcher Download-Knopf zuerst erscheint (macOS oder Windows), entscheidet dein Browser lokal anhand seiner Angaben zum Betriebssystem. Diese Angabe wird nirgendwohin gesendet.

6. Die App souldew

Die App selbst sammelt keine Nutzungsdaten und hat kein Konto. Damit sie funktioniert, nimmt sie folgende Verbindungen auf:

  • Updates: Beim Start und alle vier Stunden fragt die App bei GitHub nach einer neuen Version.
  • Mitspielen: Für SoulLinks finden sich die Apps über öffentliche Nostr-Relays und verbinden sich dann direkt (WebRTC); als Ausweichweg dient ein öffentlicher MQTT-Broker. Übertragen werden nur verschlüsselte Tracker-Daten – nie Spiele oder Spielstände.
  • Pokémon-Bilder: Sprites werden aus dem öffentlichen PokeAPI-Repository auf GitHub geladen.
  • Discord: Nur wenn du selbst einen Discord-Webhook einträgst, sendet die App Run-Ereignisse dorthin.
